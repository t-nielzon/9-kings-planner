# 9 Kings Planner

A fan-made planning tool for the roguelike strategy game 9 Kings. Pick a king, browse its cards, plan your kingdom and share a build with a link.

Live: https://9-kings-planner.netlify.app/

## Stack

React 18, TypeScript, Vite, Zustand, dnd-kit, Tailwind CSS, React Router. Hosted on Netlify.

## Run locally

```bash
npm install
npm run dev
```

`npm run build` type-checks and writes the production bundle to `dist/`. See `DEPLOYMENT.md` for hosting.
